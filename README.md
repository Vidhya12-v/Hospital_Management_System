# Smart Web Based Hospital Management System #

A Smart Web Based Hospital Management System developed to simplify hospital operations and provide better healthcare service management through a web-based platform. The system helps manage patient details, doctor availability, appointments, and hospital records efficiently.

## Features
- User and Admin Login
- Patient Registration
- Appointment Booking
- Doctor Availability Management
- Bed Availability Tracking
- Emergency Support System
- Hospital Dashboard Management

## Technologies Used

### Front-End
- JSP
- CSS3
- JavaScript

### Back-End
- Java
- Spring Boot
- Spring Data JPA

### Database
- MySQL

### Server & Build Tool
- Apache Tomcat
- Maven

### Development Tools
- IntelliJ IDEA
- Visual Studio Code

## Database Functionality
The project uses MySQL database for storing and managing:
- Patient records
- Doctor information
- Appointment details
- Bed availability data
- Hospital management details

Database operations such as insert, update, delete, and retrieval are implemented using Spring Data JPA and MySQL.

## Purpose of the Project
The objective of this project is to provide an efficient and user-friendly hospital management solution that improves accessibility and simplifies hospital administration processes.
